## SECURITY FIXES

Vulnerability 1: User ID from form
  Before: user_id = resolved_by.strip()  ← Forged by attacker
  After:  user_id = auth_user.user_id    ← From Supabase Auth UUID

Vulnerability 2: Role from environment
  Before: user_role = os.environ.get("USER_ROLE")  ← Global setting
  After:  user_role = auth_user.role              ← Per-user from session

Vulnerability 3: No authentication check
  Before: Form accessible to unauthenticated users
  After:  SessionValidator.require_authenticated_user() enforced

Vulnerability 4: Hard-coded secrets
  Before: SUPABASE_URL=https://glipboeuhpylcvqnruhu.supabase.co
